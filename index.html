Base Installation

  1. Download base Beatoraja Grab beatoraja-0.8.8-jre-win64 archive.
  2. Extract the archive
  3. Download LR2oraja Endless Dream ArenaEX. You can find it here.
  4. Rename the newly downloaded lr2oraja-0.8.8-endlessdream-windows-pre0.3.2.jar to beatoraja.jar.
  5. Drag and drop the newly renamed Beatoraja file into the game folder and overwrite the old one.
  6. Open beatoraja.exe. You will probably get a popup about an update log, close it out it doesn't matter. Next we're going to move on to the launcher settings

LAUNCHER SETTINGS (READ THE ENTIRE THING)

Player ID and Video

  1. Give yourself a name! You can always change it when joining a lobby, but it's like naming your self-insert h-game protagonist. You're the DJ of this gig!
  2. The max FPS for this game is 1000, but I find setting it to multiples of your refresh rate to be the best way of minimizing screen tearing.

    IMPORTANT TANGENT ON FPS

    Go for the highest FPS possible with your setup, Beatoraja has an issue where it can drop inputs if your FPS is too low.
    DO NOT USE VSYNC!!

Audio Settings

Optimize Your Audio Settings

  1. Every set-up is different, try using both OpenAL and PortAudio to see which one performs better.
  2. Selecting PortAudio will allow for integration with ASIO audio devices, may allow for lower audio latency as well.
  3. Check Normalize Chart Volume if you want to automatically normalize adjust all keysounds and background tracks. This is done before the song is played and is stored in disk cache.

Input Settings

  1. Make sure your game is on 7KEY.
  2. If you have an actual controller like a Phoenixwan LMT or one of the newer official Konami controllers make sure to turn on analog scratch.
  3. Lowering the minimum input duration and scratch threshold can be better for analog turntables.

Skins

  1. In the game folder you'll find a subfolder named skin.
  2. If you hate the default ModernChic skin you can find a list of skins that work with the game here.
    • I (and another anon) recommend WMII as a good starting place. Download here (Warning: Google Drive link.)
    • Another good choice is EC:FN although the archive is protected by a riddle that only the strongest JOPs with 10,000 hours in Anki can solve. Spoiler: it's donburako.
    • Finally there's LITONE 9 which is just a copy of IIDX Rootage.
  3. Once you've downloaded a skin you can put it in the skin folder and the game will automatically search it when you restart.
  4. Skins are split into categories:
    • PLAY — When you play a song.
    • MUSIC SELECT — Main menu when you first load into the game.
    • DECIDE — Is the cut-in when you select a song.
    • RESULT — After playing a song it where you see your performance.
    When choosing a skin in the launcher you need to select the Category that it belongs to and then the Skin
  5. You can change skin options in here and in-game with the F5 menu. Set the playside that you prefer. If you're new I recommend setting the Judge Detail setting to either FAST/SLOW or +-ms

Linux Guide

When playing the game on Linux it is largely the same, although there are a few key differences.

  1. Make sure to download the beatoraja-0.8.8-modernchic version instead of the bundled Windows JRE version.
  2. Beatoraja requires JRE 17 or higher, the recommended JRE is Liberica.
  3. You're going to be running the game via the beatoraja-config.command script included in the non-Windows version.
  4. Make sure to download the Linux version of LR2oraja Endless Dream ArenaEX instead of the Windows one.
  5. This game requires the correct OpenJFX version for your Java. Most package managers do not bundle it together, both the JRE and the JFX versions need to match otherwise it won't work.
  6. If you're getting errors make sure the default JRE is set correctly. On Arch you can use the archlinux-java command.
  7. Due to the differences in file path managment, some stuff might break due to capitalized characters that would otherwise be ignored on Windows. This has happened to me exactly once and never again but I thought it was worth mentioning.
